# legacy/

Upstream's demo assets, kept for provenance rather than use.

`make_gif.py` renders an animated GIF of the ORIGINAL table layout, and
`claude_monitor_demo.gif` is its output. Neither matches this fork any more: the
rows, the columns and the colours have all changed.

The screenshots in the README are produced instead by
`node scripts/screenshot.js`, which renders `monitor.js --once --demo` to SVG.

Nothing here is deleted — it is upstream's work and it documents where this fork
started.
